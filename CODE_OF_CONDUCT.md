# Code of Conduct

Mandatum follows the [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).

The project adopts it in full, including for project spaces that are not hosted by the CNCF. It applies to this repository, to any communication channel the project runs, and to project participation at events.

## Reporting

Report a Code of Conduct concern to the Maintainers listed in [MAINTAINERS.md](MAINTAINERS.md) by private message, or, if the concern involves a Maintainer or you would prefer an external channel, to the CNCF Code of Conduct Committee at <conduct@cncf.io>.

Reports are handled confidentially. A Maintainer who is the subject of a report takes no part in handling it.

## Enforcement

Consequences range from a private warning to removal from project spaces and, for a Maintainer, removal under [GOVERNANCE.md](GOVERNANCE.md) §2.4.
